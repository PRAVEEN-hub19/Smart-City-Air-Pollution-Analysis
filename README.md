# Smart City Traffic & Air Pollution Intelligence Dashboard

## Project Overview
The Smart City Traffic & Air Pollution Intelligence Dashboard is a data analytics project developed using Microsoft Power BI. It focuses on analyzing air pollution levels across different cities and identifying pollution trends over time.

The project uses air quality data to understand the distribution of major air pollutants and provide meaningful insights through interactive visualizations.

## Objectives
- Analyze air pollution levels across different cities.
- Identify trends in air quality over time.
- Understand the concentration of major air pollutants.
- Compare pollution levels using interactive filters.
- Present insights through an interactive Power BI dashboard.
